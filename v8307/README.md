# PYTHIA8.3.07 version for DarkShowers 

In a first instance, the version that was widely used for most of the studies before the version 13 was the 07, this allow to the user to study 
several Benchmark Points (BPs), such as the ones on the "Theory, phenomenology, and experimental avenues for dark showers: a Snowmass 2021 report",
but, the actual hadronisation scheme in this version was quite outdated since some of the fragmentation parameters were not rescaled properly, the
dark quark generacy hypothesis was the actual regime that this version took for the hadronisation. 

Some bugs were fixed after this version related to the Running Coupling, parton showering, etc.
